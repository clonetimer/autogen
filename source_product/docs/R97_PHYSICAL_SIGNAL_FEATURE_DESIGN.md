# R97 — 物理采样约束的振动特征与诊断算法流程设计

**状态：2026-10-25 Draft Research；基于 R96，`main` 的受限卫星仿真稳定资格不变。**

## 目的

此前的 R95/R96 可以设计“传感器子集、数值预处理、算法家族、超参数”，但没有正确利用振动传感器的**真实采样率约束**，也不能根据物理频带提出可解释的候选表征。R97 将振动特征结构变为可预先注册的“算法设计决策”，不是再开发新的诊断分类器。

```text
R93 EquipmentCard / DatasetCard / TrialSpec (TRAIN only)
      ↓ 物理采样率、源记录身份和合法可观测性
R97 两种预注册振动特征表达
      ├─ time_rms_crest: 4096 采样技术窗口 → RMS 与峰值系数
      └─ time_plus_frequency_bands: 以上 + 50–500 Hz、
                                     500–8000 Hz Hann FFT 频带能量占比
      ↓ 每一份原始记录只产生一条聚合特征记录
R96 传感器子集 + TRAIN 折内拟合的标准化/鲁棒变换
      ↓
R94 原有 torch_like 算法运行时 (Linear, Tree 等)
      ↓
R95 源 TRAIN 物理留组 OOF 比较 → 临时短名单 / 拒绝
```

**两个特征方案共享一个试验预算**：预算均分到两个配方，配方内部只选 R94 真正实现的算法，所有物理留组折不变，整体最多 64 次源拟合。优先比较算法家族在相同完整特征/基础预处理条件下的性能，之后才探索额外数值处理。记录拟合次数，但这**不表示** FLOPs、时间、CPU/GPU 或耗电成本已完全一致。

## 明确边界

- 支持设备的唯一目标原始传感器必须是 `EquipmentCard` 中**明确定义为 vibration**、可用于本任务、标称采样率 20k–200kHz 的通道；目前固定频带上限 8000Hz。未在任务注册的传感器不能自动作为输入。
- 每个 `record_id` 必须提供 `sample_rate_hz`、至少 4096 个、最多 1,000,000 个**有限数值样本**；采样率须和设备合同声明严格相同，不能猜测、自动重采样或将 12kHz 与 48kHz 波形混作可比谱特征。
- 4096 个**不重叠技术窗口**用于内部计算 RMS、crest factor 和 Hann 加窗的 FFT；最终对所有窗口的每个特征取中位数，形成**原始记录层级的一行数据**，保持 DatasetCard 中原物理设备、采集会话、原始数据角色及分组不变。
- 频带能量占比按真实**声明**采样率构造 Hz 频率轴，能量分母为 50Hz 以上能量；不能将这些比值解释为已校准的绝对功率、真实轴承故障频率、包络解调峰值或物理缺陷尺寸。
- 任何记录缺少原始样本、样本含 NaN/Inf/布尔量、标称采样率冲突、越界、异常的标量通道或企图携带 label/role，均在**模型训练开始前**拒绝。
- SHA-256 绑定**经 float64 小端转换的数字样本内容**；与磁盘原始 MAT/CSV 文件的 SHA-256 不是同一个概念。当前接口不核验工业文件字节真实性，也不认证仪器时钟/传感器校准。后续 P2/真实数据入口承担此职责。
- 前端自动算法设计是源训练集内部研究：源验证同样可以对选择造成乐观偏差，**不能**将内部短名单称为外部独立验证的模型。
- 没有硬件或真实故障组时拒绝性能结论，不能将 59 个振动窗口冒充 59 个独立轴承。

### 公开真实测量数据的第二层证据

另外增加`r97_cwru_signal_probe`，从 CWRU 官方 HTTPS 重新获取 R91 已确认的原始 `97.mat`、`109.mat`，要求它们逐字节匹配 2026-10-25 首次记录的 SHA-256，并确认 `X097_DE_time` / `X109_DE_time` 变量，然后按同一 R97 特征算法输出**特征统计收据**。将其作为**独立 GitHub CI 作业**运行，仅保留 JSON 收据，不提交/分发原始 MATLAB 文件。

```powershell
$env:PYTHONPATH="src"
python -m phm_design.industrial_contracts.r97_cwru_signal_probe --receipt cwru_r97_original_feature_audit.json
```

下载失败必须报错，不得回退合成数据；原始文件字节与首次记录不同也必须明确报告漂移。下载历史 SHA 仅证明与首轮 URL 取回的内容一致，不代表数据发布方的数字签名或传感器标定证书。

**两份真实 CWRU 原始信号只能证明物理频带特征在真实测量上能计算**。只有健康 97 与故障 109 两个文件，无法鉴别足够多的独立轴承、工况与失效机理来形成统计可靠的泛化对照，因而这个作业**不进行任何模型拟合**，不得给出诊断准确率或模糊机制效果。

## 后续研发主线（不改变）

1. 将频域/时域候选拓展为可验证的包络谱、频谱峰值、采样对齐与转速阶次；**只有设备元数据具备物理支持才能注册**。
2. 在物理设备身份可核验的数据上研究与优化处理—特征—模型流程的组合结构，而不是只靠固定穷举或在同一数据反复调参。
3. 对照统计/线性/树/神经网络及可选自组织模糊方案的多目标价值，全面记录物理分组、训练成本、最差工况误报和不确定性。
4. 外部独立验证与可复现制品后，再决定是否允许针对某一设备/工况出具部署资格。当前主干 Stable 不变。

**R97 的验收对象是诊断算法方案自动设计机制与可追溯物理信号变换，不是新的模型精度纪录。**
